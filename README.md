# C/C++ Object-Oriented Programming Lab Work

A structured collection of C and C++ programming exercises covering fundamental programming concepts and progressively advanced Object-Oriented Programming techniques.

The repository contains implementations developed through laboratory exercises, progressing from procedural C programming and pointers to C++ classes, constructors, operator overloading, inheritance, polymorphism, exception handling, dynamic memory management, and file processing.

## Features

* C programming fundamentals
* Arrays, strings, pointers, and recursion
* Dynamic memory allocation
* C++ classes and objects
* Constructors and destructors
* Function and operator overloading
* Friend functions
* Inheritance and multiple inheritance
* Runtime polymorphism and dynamic binding
* Custom exception handling
* File input/output
* Menu-driven console applications
* Basic input validation and error handling

## Installation

### Requirements

* GCC/G++
* C++17 or later
* Git

Verify the compiler installation:

```bash
g++ --version
gcc --version
```

Clone the repository:

```bash
git clone https://github.com/<your-username>/cpp-oop-lab-portfolio.git
cd cpp-oop-lab-portfolio
```

## How to Run

### C++

Compile a C++ program:

```bash
g++ -std=c++17 "Lab Exercise 7/Ex2.cpp" -o program
```

Run:

```bash
./program
```

### C

Compile a C program:

```bash
gcc -std=c11 "Lab Exercise 2/Ex1.c" -o program
```

Run:

```bash
./program
```

For programs using the math library, compile with:

```bash
gcc -std=c11 "Lab Exercise 2/Ex2.c" -o program -lm
```
